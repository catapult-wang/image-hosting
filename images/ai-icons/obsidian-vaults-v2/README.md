# Obsidian 风格图标集 · V2

36 枚图标：10 个主题 + 26 个大写英文字母。制作日期：2026-09-26。

本套面向桌面快捷方式及插件图标选择器：扩大中心识别元素、加粗白色符号、保留切面黑曜石风格。字母组以同一张紫色水晶底板为参考逐个生成。

## 文件

- `index.html`：可切换尺寸、深浅背景和分类的本地预览页。

- `themes/`：10 个主题，透明 PNG 与多尺寸 ICO。
- `letters/`：A–Z，透明 PNG 与多尺寸 ICO。
- `manifest.json`：稳定英文 ID、中文主题名及相对路径，供插件加载。
- `preview-themes.png`、`preview-letters.png`：大图及浅/深色背景的实际 16、24、32 像素预览。
- `provenance/`：共用底板、生成提示词和转换/预览脚本。

ICO 包含 16、24、32、48、64、128、256 像素图层。PNG 保留 imagegen 原始透明通道。
